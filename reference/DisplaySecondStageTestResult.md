# DisplaySecondStageTestResult

DisplaySecondStageTestResult

## Usage

``` r
DisplaySecondStageTestResult(logodds, sigma, self.design = FALSE, places = 5)
```

## Arguments

- logodds:

  the log odds ratio vector

- sigma:

  the covariance matrix of the log odds ratio vector

- self.design:

  self design matrix

- places:

  numerical places to keep
