# Calcualte the fixed effect score test p value based on score and information matrix

Calcualte the fixed effect score test p value based on score and
information matrix

## Usage

``` r
DisplayFixedScoreTestResult(score, infor, places = 5)
```

## Arguments

- score:

  the score vector

- infor:

  the information matrix for the score

- places:

  the numerical places to keep
