# Simulated breast cancer data

A simulated case-control dataset used in TOP examples. The first column
is disease status; columns 2 through 5 are tumor characteristics; column
6 is a simulated SNP dosage; and column 7 is a principal component.

## Usage

``` r
data
```

## Format

A data frame with 10,000 rows and 7 variables.

## Source

Simulated for the TOP package.
