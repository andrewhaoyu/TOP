# Security and privacy

TOP is statistical software and should not receive participant-level
data in public issues, pull requests, or example repositories.

For a vulnerability that could expose data, corrupt results silently, or
crash an R session, email <andrew.haoyu@gmail.com> before opening a
public issue. Include the TOP version, R version, operating system, and
a synthetic reproducer when possible. The maintainer will acknowledge
the report and coordinate a fix and disclosure timeline.
